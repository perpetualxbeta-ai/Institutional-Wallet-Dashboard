# Institutional Wallet Dashboard

A vibe-coded, interactive dashboard designed to demonstrate and explore how institutional-grade crypto wallets operate, complete with a mock interface to simulated blockchain interactions.

## 📌 Overview

Managing institutional crypto assets requires multi-layered security, role-based access control, transaction policy enforcement, and multi-signature authorization workflows. This project serves as an educational and interactive simulator that breaks down these complex mechanisms into an intuitive dashboard interface.

## ✨ Key Features

* **Institutional Wallet Management**: Visualize multi-sig account structures, vault management, and asset breakdown across different networks.
* **Policy & Approval Engine**: Simulate multi-approver workflows, spending limits, quorum requirements, and role-based access controls (RBAC).
* **Mock Blockchain Interface**: Execute simulated transactions, monitor pending approvals, and inspect mock transaction logs on a simulated ledger without interacting with mainnet or testnet networks.
* **Real-time Activity Feed**: Track wallet actions, signature collections, and execution states in real time.

## 🛠️ Tech Stack

* **Language**: TypeScript
* **Styling**: CSS / Tailwind
* **Environment**: Node.js & [Replit](https://replit.com/@perpetualxbeta/Institutional-Wallet-Dashboard)
* **Package Manager**: `pnpm`
